# AWTRIX NG Blueprints — User Manual

**⬇️ Download the blueprints:** sponsor on **[Ko-fi](https://ko-fi.com/s/0d1e4419bd)** — lifetime updates, re-download whenever a new version is released.

Since V6.1 the AWTRIX NG blueprints come in two sets, each with its own manual. Pick the one for your clock:

| Clock | Files | Blueprint names | Manual |
|---|---|---|---|
| **Ulanzi TC001** | `awtrix_ng_*.yaml` | *AWTRIX NG …* | ➡️ **[AWTRIX NG TC001 manual](AWTRIX-NG-TC001-MANUAL.md)** |
| **Ulanzi TC002** | `awtrix_ng_tc002_*.yaml` | *AWTRIX NG TC002 …* | ➡️ **[AWTRIX NG TC002 manual](AWTRIX-NG-TC002-MANUAL.md)** |

The `awtrix_ng_*.yaml` files still exist and are now meant specifically for the TC001. The `awtrix_ng_tc002_*.yaml` files are made specifically for the TC002.

Running AWTRIX 3? See the **[AWTRIX 3 manual](AWTRIX-3-MANUAL.md)**.
